# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/QuentinBtd/gerrit-branch-review/security/advisories/new)
for this repository. Do not open a public issue for security problems.

Include the plugin version, Gerrit version, a description of the impact and, if possible, a
minimal reproduction. You will get an acknowledgement after the report is triaged; fixes are
released as patch versions and disclosed in a GitHub security advisory.

## Supported versions

Only the latest released minor version receives security fixes during the `0.x` phase.

## Scope

The plugin's security model, permission checks and known visibility considerations are
documented in [docs/security.md](docs/security.md).
